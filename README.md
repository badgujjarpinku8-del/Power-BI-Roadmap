# Power BI Roadmap

## About This Project
This project presents a handwritten roadmap for learning Microsoft Power BI, from data preparation to real-world data analytics projects.

## Learning Roadmap

1. **Data Sources:** Excel, CSV, and SQL
2. **Power Query:** Data cleaning, changing data types, removing duplicates, merging and appending queries.
3. **Data Modeling:** Relationships, star schema, fact tables, and dimension tables.
4. **DAX:** SUM, CALCULATE, FILTER, IF, COUNT, DISTINCTCOUNT, and time intelligence.
5. **Visualizations:** Cards, bar charts, column charts, line charts, maps, slicers, and KPIs.
6. **Dashboards:** Sales, finance, HR, and customer dashboards.
7. **Power BI Service:** Publishing, workspaces, scheduled refresh, sharing, security, and gateways.
8. **Real-World Projects:** Build projects and showcase them in a GitHub portfolio.

## Tools Covered
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- CSV files
- SQL
- GitHub

## Project Goal
To create a structured learning guide for beginners who want to develop Power BI and data analytics skills through practice and projects.
